# Статична браузерна версія MOMO

Основний інтерфейс: `site/`. GitHub Pages публікує його копію з `docs/` на main. Сайт не має серверного API; усі модулі, WASM, приклад і ваги завантажуються відносними URL з одного origin.

## Модель

Validation-selected CNN, seed42, checkpoint6. ONNX-граф містить нормалізацію0…1 →−1…1, нейронні шари й softmax та повертає64 ознаки для персоналізації. Власного forward шарів немає: їх обчислюють ONNX Runtime і TensorFlow.js. Початкова різниця ONNX/PyTorch становить1.788e-7; початковий TFJS-класифікатор зі скопійованими вагами збігається з ONNX до4.769e-7. Дивіться [персональне навчання](PERSONALIZATION.md).

Передобробка малюнка: alpha-aware перетворення кольорових штрихів на grayscale; threshold/8-connected component cleaning; поділ за вертикальною проєкцією; браузерне масштабування до20×20, padding28×28, bilinear центрування за центром мас. Вона схожа за задумом на Python-версію, але Canvas resampling не дорівнює PIL Lanczos, тому Python accuracy не переноситься на сайт.

Перевірені UI-сценарії: приклад407→407; рукописне111→111 на мобільному макеті; порожній ввід; resize із очищенням результату. Unit-тести перевіряють порядок сегментів, злиття дрібного внутрішнього розриву, шум і строгий діапазон.

## Залежності та відтворення

ONNX Runtime Web1.31.1 зафіксовано в `tools/prepare_web.py`. Runtime не залежить від зовнішнього CDN. При першому відкритті завантажується близько15МБ статичних runtime/model-файлів; сучасний браузер має підтримувати WebAssembly/SIMD. Є індикація завантаження та повторна спроба при помилці.

Потрібні встановлені Python-залежності дослідження та додатково `onnx` для повторного експорту. `tools/prepare_web.py` читає локальні checkpoint, метрики й приклад із збереженого MNIST test. Публікація готового сайту цих залежностей не потребує.

```sh
node --test site/tests/segmentation.test.mjs
python tools/build_pages.py
python tools/serve_site.py
```

Сторінка `/verify.html` запускає тест ONNX/PyTorch та111 у справжньому браузері. Після змін preprocessing необхідно окремо переоцінювати його якість: цей тест підтверджує лише graph parity і контрольний сценарій, а не accuracy на довільному почерку.
