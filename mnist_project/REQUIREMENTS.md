# Відповідність уточненим вимогам

| Вимога | Де перевірити |
| --- | --- |
| Обрати задачу машинного навчання | Класифікація рукописних цифр 0–9; `research.ipynb`, `REPORT.md` |
| Представити один датасет | `DATASET.md`: походження MNIST, формат, приклади, баланс, поділ і обмеження; також включено в Notebook і звіт |
| Розглянути наукові статті | `LITERATURE.md`: 3 публікації, короткий огляд, зв'язок із реалізацією та межі висновків; також у Notebook і звіті |
| Навчити 3 моделі різної складності на цьому датасеті | LogisticRegression → MLP → CNN; `experiment.py`, `models.py`, історії, ваги та `training_summary.csv` |
| Оцінити точність | Спільний test 10000; accuracy, macro-F1, per-class precision/recall/F1, confusion matrices |
| Порівняти швидкість та інші характеристики | `benchmark.py`, `COMPARISON.md`, `artifacts/model_comparison.csv`: час навчання, single/batch inference, параметри, MAC, розмір файлу |
| Зробити звіт і пояснити компроміс | `REPORT.md` та виконаний `research.ipynb`; підсумок у `COMPARISON.md` |
| Використати ML-бібліотеки, без алгоритмів з нуля | scikit-learn LogisticRegression, PyTorch nn/autograd/Adam, sklearn.metrics |

CNN_aug — додатковий експеримент з тією самою CNN, а не заміна третьої моделі. Основне порівняння використовує базові моделі без аугментації. Нейромережі мають по три seeds, регресія — один запуск; кількість повторів показано відкрито.

Сайт MOMO, синтетичні багатозначні числа й персональне донавчання — додаткові демонстрації. Вони не заміняють дослідження й не входять у порівняння фіксованих моделей. Усний виступ із демонстрацією екрана готується пізніше; окрема презентація слайдів зараз не створюється.
