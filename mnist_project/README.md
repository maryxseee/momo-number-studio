# MNIST: моделі, аугментація та стійкість

**Публічна браузерна демонстрація MOMO:** [maryxseee.github.io/momo-number-studio](https://maryxseee.github.io/momo-number-studio/). Новий рожево-жовтий інтерфейс працює автономно через ONNX Runtime Web; його вихідний код у кореневому `site/`. Наведені нижче `app.py` та `/digit` — окрема локальна Python-демонстрація. Browser Canvas preprocessing відрізняється від PIL/SciPy; 90,6% не заявляється як точність сайту.

Основна розширена робота. Попередній Digits — окремий вступний експеримент у батьківській папці, він не є джерелом чисел цього проєкту.

## Експеримент

- Дані: MNIST, офіційні 60000/10000; train ділиться на 50000 train та 10000 validation.
- Класифікатори: LogisticRegression, MLP, CNN, CNN з геометричною аугментацією.
- Для трьох нейронних варіантів seeds 17/42/73: **9 запусків, 54 епохи сумарно**. Базова регресія — один запуск.
- Однаковий бюджет: 6 епох, batch 256, Adam. Checkpoint за validation macro-F1.
- Чистий test та 6 видів спотворень; всього 10 моделей × 7 умов × 10000 зображень = **700000 оцінювань зображення**.
- Основна перевірка: парний ефект аугментації на ±20° та зсуві 3 px; якість на чистих даних аналізується окремо.
- Статистика: mean/sample std трьох seeds; per-class report, confusion matrices, Wilson interval та описова reliability/ECE діагностика.
- Демонстрація: локальний canvas, top-3 softmax, показ передобробки; дані не зберігаються.

## Встановлення

Перевірено на Python 3.12, Windows x64, CPU. У цій папці:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Залежності PyTorch завантажуються з офіційного CPU-репозиторію. GPU не потрібен. `requirements-lock.txt` фіксує повний список пакетів середовища запуску; `requirements.txt` — прямі залежності. На іншій платформі використайте відповідні wheels PyTorch/torchvision із сумісною парою версій.

## Відтворення з нуля

```powershell
python experiment.py
python evaluate.py
python evaluate_numbers.py
python benchmark.py
python report.py
python build_research.py --execute
python -m unittest discover -s tests -v
```

Перший запуск завантажує MNIST. Для повторного офлайн-навчання достатньо збереженої папки `data/MNIST/raw`. Перша команда використовує завершені запуски, якщо вони є; для нового незалежного виконання спочатку **перейменуйте `artifacts` як резервну копію**. Не підбирайте нові параметри за результатами вже відкритого test. На іншому процесорі час може суттєво відрізнятися. Для навчання PyTorch задано два CPU threads.

Автовідновлення перевіряє конфігурацію, але не зміни Python-коду. Після зміни архітектури, preprocessing або training loop також починайте з нової папки артефактів. Release manifest фіксує hashes файлів готового пакета, а не замінює цю перевірку. Команда `python package_project.py` формує ZIP із Notebook, кодом, результатами й усіма дев'ятьма checkpoint; бібліотеки та `data/` до ZIP не включаються.

Notebook за замовчуванням читає виконані експерименти, показує код і результати та не повторює навчання. Це позначено в його першій клітинці. Для запуску навчальних скриптів із Notebook встановіть `RETRAIN=True`; правила повторного використання артефактів зберігаються.

Відкрити Notebook можна у VS Code з Jupyter extension. Альтернатива: додатково встановити `jupyterlab`, виконати `python -m jupyterlab` та відкрити `research.ipynb`.

## Запуск демонстрації

```powershell
python app.py
```

Відкрийте **http://127.0.0.1:8765**. Намалюйте одне число **1–1000** в один рядок, залишаючи проміжки між цифрами, і натисніть «Розпізнати число». Рамки показують знайдені цифри, картки — їхні top-3 оцінки та входи CNN. Нуль, провідні нулі та значення понад 1000 відхиляються; злиті або багаторядкові цифри надійно не підтримуються. Попередній режим однієї цифри 0–9 збережений за **http://127.0.0.1:8765/digit**. Завершення сервера: Ctrl+C. Інший порт: `python app.py --port 8766`. Запускати сервер потрібно з активованого середовища; інтернет для демонстрації не потрібен.

Модель для демонстрації автоматично вибрано за validation macro-F1 серед збережених нейронних запусків. Softmax не є каліброваною впевненістю. Самостійні малюнки мають інший розподіл, ніж MNIST, тому очікувані помилки. Демонстрація не видається за зовнішнє оцінювання точності.

## Межі висновків

Дослідження обмежене шістьма епохами, одним розбиттям і трьома seeds. Відмінність між seeds не є оцінкою всіх джерел невизначеності. Зміна почерку, фото, фону та освітлення потребує окремих даних. Test не використовувався для підбору параметрів; виконання скриптів після перегляду результатів має зберігати цю дисципліну. Конкретний бал визначає викладач.

В архіві не містяться встановлені бібліотеки. Ваги невеликі; навчальні дані завантажуються офіційним loader. Використано готові алгоритми sklearn і PyTorch autograd, без реалізації ML-алгоритмів з нуля.
