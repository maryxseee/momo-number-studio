# Захист дослідницького проєкту

## Доповідь на 3–4 хвилини

Моя задача — розпізнавати рукописні цифри від 0 до 9. Я порівнюю логістичну регресію, перцептрон, згорткову мережу й ту саму згорткову мережу з аугментацією. Основне дослідницьке питання: чи дає геометрична аугментація стійкість до поворотів і зсувів та як це впливає на якість чистих зображень.

Використовую MNIST. Із 60000 офіційних навчальних зображень виділив 50000 для навчання й 10000 для валідації. Офіційні 10000 тестових прикладів використовую після завершення вибору моделей. Поділ стратифікований і спільний для всіх моделей. Пікселі масштабуються фіксованим перетворенням, без обчислення статистик на test.

Логістична регресія є лінійним орієнтиром. MLP обробляє зображення як вектор. CNN зберігає просторову структуру й використовує готові згорткові шари. Я не реалізовував backpropagation: градієнти обчислює PyTorch autograd, ваги оновлює Adam.

Для трьох нейронних варіантів виконано по три запуски, разом дев'ять. Кожен триває шість епох. Найкращий checkpoint обирається за validation macro-F1. У парі CNN/CNN_aug для того самого seed початкові ваги та порядок прикладів однакові; різниця — наявність аугментації. Це допомагає відокремити ефект методу від випадкової ініціалізації.

На test я вимірюю accuracy, macro-F1 і показники кожного класу. Для спотворень порівнюю парні різниці всередині seed, а не найкращі окремі запуски. Числа для доповіді потрібно взяти з розділів 5–6 REPORT.md: середня accuracy моделей, зміна геометричної стійкості та зміна чистої accuracy. Графіки навчання й помилок пояснюють результат ширше за одне число.

Для практичного застосування створено локальний інтерфейс малювання. Він показує передобробку, прогноз і top-3 оцінки. Ці оцінки не є гарантією правильності; самостійно намальовані цифри відрізняються від MNIST. Результат дослідження — виміряний ефект аугментації за конкретного бюджету, а не твердження, що один метод завжди кращий.

## Питання й відповіді

**Як розпізнаються числа 1–1000?** Це послідовність із 1–4 цифр, а не 1000 класів. Після очищення цифри виділяються за вертикальною проєкцією, сортуються зліва направо, проходять ту саму CNN й об'єднуються. Потім перевіряється діапазон. Для 1001 чи провідного нуля показується повідомлення, а прогноз не виправляється штучно.

**Як оцінюється правильність усього числа?** Exact-number accuracy: усі цифри й порядок мають бути правильними. Окремо перевіряються кількість сегментів та IoU рамок. Контроль із відомими межами використовує таке саме очищення й CNN.

**Чому не просто показати 98% точності цифр?** Число неправильне навіть за однієї помилки. Для багатозначних чисел exact-number accuracy зазвичай нижча. Фактичні числа наведено в NUMBERS.md.

**Чи доведена точність для справжніх рукописних чисел?** Ні. Перевірено синтетичні композиції окремих test-цифр MNIST з проміжками й без проміжків між рамками. Нульовий проміжок не гарантує фізичного контакту штрихів. Потрібен окремо зібраний розмічений набір цілих чисел від нових авторів.

**Де навчання?** `experiment.py`: у циклі mini-batches обчислюється cross-entropy, викликаються loss.backward() та optimizer.step(). sklearn-регресія навчається через fit().

**Це порушує заборону писати forward/backprop з нуля?** Ні. Архітектури зібрані з готових nn.Linear/Conv2d/ReLU/MaxPool; математику шарів і похідних виконує бібліотека. Навчальний цикл організовує виклики готових компонентів.

**Навіщо validation і test окремо?** Validation обирає епоху й checkpoint; test оцінює вже зафіксовану процедуру. Вибір найкращого seed за test зробив би оцінку оптимістичною.

**Що таке logits?** Числові виходи останнього шару до softmax. CrossEntropyLoss приймає саме їх і внутрішньо виконує потрібне стабільне перетворення.

**Чому не 100 епох?** Це наперед зафіксований CPU-бюджет. Довше навчання — інший експеримент. У висновках прямо зазначено, що шість епох не гарантують збіжності чи оптимальності всіх варіантів.

**Чому однакові seeds?** Для парного порівняння. Початкові ваги перевірені hashes, shuffle має власний generator, а augmentation — окремий. Після першого кроку ваги закономірно розходяться.

**Чим CNN відрізняється від MLP?** CNN використовує локальні спільні фільтри й зберігає просторові сусідства пікселів. MLP після Flatten не має такої вбудованої структури. Згортковість не гарантує інваріантності до всіх поворотів чи зсувів.

**Чи mean ± std — довірчий інтервал?** Ні. Тут це середнє й sample std по трьох навчальних seeds при одному розбитті. Wilson-інтервал оцінює іншу невизначеність — частку правильних відповідей одного checkpoint на test за припущення незалежності прикладів.

**Чи доведено статистичну значущість?** Ні. Три seeds — обмежене описове дослідження. Ми показуємо розкид та індивідуальні парні різниці, не заявляємо надійного статистичного доказу.

**Чому test-поворот більший за навчальний?** Навчання використовує ±15°, оцінювання ±20°: перевіряється перенесення стійкості трохи за межі навчальних перетворень.

**Чи зсув 3 px теж поза навчальним діапазоном?** Не обов'язково. Параметр зсуву задається в оберненій нормалізованій affine_grid сітці; спільне застосування масштабу й повороту змінює фактичний прямий зсув. Тому для нього такого твердження не робимо.

**Чи аугментація допомагає завжди?** Ні. Вона змінює навчальний розподіл і може погіршувати чисту якість при тому самому бюджеті; геометрія не навчає автоматично стійкості до noise/dilation/erosion.

**Чому train loss може бути вищим за validation?** Train loss вимірюється з dropout та, для CNN_aug, на складніших аугментованих входах під час оновлень ваг. Validation — у eval на чистих входах після епохи.

**Що таке ECE?** Зважена за кількістю прикладів середня абсолютна різниця між середнім softmax score і фактичною accuracy всередині bins. Вона залежить від вибору bins і не доводить надійності на іншому домені. Калібрування моделі на test не проводилося.

**Чому демонстрація може помилятися?** Товщина, форма й положення штриха з canvas відрізняються від MNIST. Передобробка зменшує частину розбіжності, але не усуває зміну домену. UI не є розміченим зовнішнім benchmark.

**Що зробити далі?** Заздалегідь запланувати довше навчання, окремі види аугментації, повторні розбиття та тест на малюнках незалежних авторів.
